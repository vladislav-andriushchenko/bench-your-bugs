Based on the search results, the flag that forces Stryker to run all mutants, even if incremental is provided and an incremental file exists (which can be used to force a rebuild of the incremental file), is the `--force` flag.
Additionally, Stryker documents combining `--incremental` with `--force` and a narrow `--mutate` pattern for targeted reruns.
