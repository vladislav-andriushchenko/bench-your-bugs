Согласно официальной документации вендора, для интеграции с Test IT доступны следующие сервисы:
Российские сервисы: YandexGPT (функция стартовала с поддержки российского YandexGPT весной 2025), GigaChat.
Универсальные решения: сервисы, совместимые с OpenAI API — пользователи могут подключать любые нейромодели, совместимые со стандартом OpenAI API, включая Anthropic, DeepSeek, OpenAI и другие.
Дополнительно: в 1 проект можно добавить до 3 ИИ-сервисов, выбор сервиса осуществляется при генерации тестов.
