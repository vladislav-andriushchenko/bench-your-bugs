Для генерации тест-кейсов на основе задач из вашего таск-трекера вы можете настроить интеграцию с ИИ-сервисами, совместимыми с OpenAI и соответствующие стандарту API OpenAI.
Согласно официальной документации Test IT, доступны следующие ИИ-сервисы:
Встроенные интеграции: YandexGPT (настройка в Yandex Cloud, платная услуга); GigaChat (аккаунт в Сбер Developer Studio с проектом GigaChat API Business).
Сервисы, совместимые с OpenAI API: к ним относятся Anthropic, Deepseek, OpenRouter и Qwen. Интеграции со всеми сервисами настраиваются аналогичным образом. Пользователи могут подключать в TMS любые нейромодели, совместимые со стандартом OpenAI API.
Требуемые параметры: Base URL, API Key, Модель AI.
