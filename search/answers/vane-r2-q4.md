Согласно официальной документации вендора, для интеграции с Test IT доступны следующие категории ИИ-сервисов:
1. Российские LLM-модели: YandexGPT (исключение — речевые модели), GigaChat (исключены эмбеддинг-модели).
2. Сервисы, совместимые со стандартом OpenAI API. Test IT позволяет подключать любые нейромодели, совместимые со стандартом OpenAI API. В документации вендора упоминаются: Anthropic, Deepseek, OpenRouter, Qwen.
Параметры настройки: Base URL (обычно заканчивается /v1), API Key, Модель AI.
Дополнительно: конфиденциальность (не передавать данные под NDA), изображения и вложения не обрабатываются, ИИ-генерация платная, для Test IT Облако на Yandex Cloud может потребоваться whitelist IP при подключении сервисов за закрытым сетевым контуром.
