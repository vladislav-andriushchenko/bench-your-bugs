Отечественные LLM: в режиме MVP платформа предлагает генерацию тестов на основе задач из багтрекера через интеграцию с Yandex GPT и GigaChat.
Расширение через OpenAI API: теперь пользователи Test IT могут подключать к TMS любые нейромодели, совместимые со стандартом OpenAI API.
Итоговый перечень доступных вариантов:
1. Yandex GPT — отечественная модель, доступная через прямую интеграцию с Test IT.
2. GigaChat — отечественная модель от Сбера, также доступна через прямую интеграцию.
3. Любые нейромодели, совместимые с OpenAI API — гибкий вариант, открывающий доступ к сотням моделей.
