# 02-orders

Заложено:

- `add_line` — изменяемый список как значение по умолчанию, копится между вызовами.
- `vat_amount` — целочисленное деление `//` на 100 до умножения обрезает остаток:
  для 150 центов при ставке 20 процентов вернёт 20 вместо 30. Чем меньше сумма,
  тем больше относительная потеря; на 99 центах вернёт 0.
- `last_pages` — срез `start + per_page - 1` отрезает по одному элементу с каждой
  страницы, часть данных теряется.

Чисто:

- `order_label` — форматирование корректно.
- `total_with_vat` — сам по себе верен, ошибка живёт в `vat_amount`.
