# 04-concurrency

Заложено:

- `claim_slot` — проверка и запись в `RUNNING` не под замком. Два потока с одним
  `job_id` оба получат `True`, и задача выполнится дважды.
- `write_pid` — то же самое между `os.path.exists` и `open`: два процесса пройдут
  проверку одновременно, второй затрёт pid первого.

Чисто:

- `bump_counter` — инкремент и возврат под замком, всё верно. Модель, отметившая его,
  реагирует на слово `global`, а не на поведение.
