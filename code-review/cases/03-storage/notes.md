# 03-storage

Заложено:

- `find_user` — SQL склеивается строками, логин попадает в запрос как есть.
  Логин `' OR '1'='1` вернёт первого пользователя таблицы.
- `dump_report` — файл закрывается только при успехе. Любое исключение внутри цикла
  (например, `row` не из строк) оставляет дескриптор открытым и файл недописанным.
- `load_config` — голый `except Exception: pass` возвращает `None` вместо содержимого,
  и вызывающий код не отличит пустой файл от отсутствующего или битого.

Чисто:

- `status_label` — чистый поиск по словарю с запасным значением.
- `open_db` — обёртка без ошибок, но соединение закрывает вызывающий, поэтому
  в `forbid.txt` не вынесен: замечание про незакрытое соединение защитимо.
