# 01-tokens

Заложено:

- `issue_stamp` — `created_at or time.time()` проглатывает валидный 0 (полночь 1970-го,
  а на практике любой счётчик, начинающийся с нуля) и подставляет текущее время.
- `split_token` — `raw.split(".")` роняет ValueError на строке без точки или
  с двумя точками; распаковка в две переменные не защищена.

Чисто (не должно всплывать):

- `clamp_ttl` — работает верно.
- `is_alive` — арифметика корректна.

`is_alive` в `forbid.txt` не вынесен намеренно: при `created_at` из будущего
`now - created_at` отрицательно и функция считает токен живым. Замечание защитимо,
значит наказывать за него нельзя.
